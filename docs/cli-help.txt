chosko-llm — manage global Claude Code commands and skills.

Usage:
  chosko-llm ls                       List all features with installed version, latest version, and
                                      status (up-to-date / updatable / not installed / local only /
                                      superseded / migration pending). The last two flag a feature
                                      mid kind-migration; 'update --all' resolves them.
  chosko-llm ls --installed           Show only features currently installed under $CLAUDE_HOME.
  chosko-llm ls --available           Show only features present in the managed clone.

  chosko-llm show <feature>           Inspect a single feature: name, kind, installed/latest
                                      version, status, description, and path. Add --content to
                                      also print its body.
  chosko-llm show <feature> --diff    Compare the installed copy against the managed clone.
                                      Use --diff --content for a line-by-line diff. --installed
                                      and --latest pick which copy to show.

  chosko-llm add <feature> [<feature>…]  Copy one or more features from the managed clone into
                                      $CLAUDE_HOME. Errors if a feature is already installed (use
                                      'update'). With multiple names, each is installed
                                      independently: a failure on one (already installed, unknown
                                      name, wrong scope for the kind) is logged and the rest still run;
                                      exit code is 1 if any failed. e.g. 'add foo skill:bar claude-md:baz'.
  chosko-llm add --all                Install all features from the managed clone that are not yet
                                      installed. Already-installed features are skipped. Cannot be
                                      combined with explicit feature names.
  chosko-llm rm  <feature>            Delete an installed feature from $CLAUDE_HOME.
  chosko-llm update <feature> [<feature>…]  Re-copy one or more features from the managed clone
                                      (installs any that are missing). Same best-effort, multi-name
                                      behavior as 'add'. e.g. 'update foo skill:bar claude-md:baz'.
  chosko-llm update --all             Update every installed feature whose version is lower than the
                                      managed clone (skips up-to-date and locally-ahead features).
                                      Also migrates a feature that changed kind: if an installed
                                      artifact has no source in the clone but another feature there
                                      declares it as 'replaces:', the replacement is installed and
                                      the stale copy removed. This is how the context-build and
                                      context-update commands became skills — after 'upgrade', a
                                      single 'update --all' completes the move.

  --local / --global (on ls, show, add, rm, update)
                                      --local installs into <cwd>/.claude instead of $CLAUDE_HOME,
                                      for a per-repository install — claude-md artifacts inject into
                                      <cwd>/CLAUDE.md itself. Requires <cwd>/CLAUDE.md to already
                                      exist (run from the project root; run /project-setup first on
                                      an empty directory). --global targets $CLAUDE_HOME (the
                                      default). statusline scripts are global-only: a single-feature
                                      statusline request with --local fails; '--all --local' skips
                                      statusline silently; 'ls --local' omits it entirely; 'show
                                      --local' on a statusline feature reports it as global-only.
                                      hooks are local-only, the exact mirror: a single-feature hook
                                      request without --local fails; '--all' in global scope skips
                                      hooks silently; 'ls --global' omits them; 'show --global' on a
                                      hook reports it as local-only.

  chosko-llm upgrade                  git pull the managed clone and refresh the CLI proxy.
                                      Does NOT re-install features — use 'update --all' for that.
                                      Runs automatically once a day on the first command (opt-in;
                                      enabled at install). Toggle with the flags below.
  chosko-llm upgrade --enable-auto    Enable daily auto-upgrade (sets the preference; no upgrade).
  chosko-llm upgrade --disable-auto   Disable daily auto-upgrade (sets the preference; no upgrade).

  chosko-llm channel                  Print the branch ('channel') the managed clone is on.
  chosko-llm channel --list           Fetch origin and list the channels you can switch to,
                                      marking the current one (also: -l).
  chosko-llm channel <branch>         Switch the managed clone to <branch> to try unmerged work:
                                      fetch, checkout, fast-forward, and refresh the proxy. Then
                                      run 'update --all' to deploy its features. Back to stable
                                      with 'chosko-llm channel master'.

  chosko-llm export [<repo>]          Package <repo>'s Claude config (CLAUDE.md, AGENTS.md,
                                      README.md, curated .claude/*.md|json|toml) into one
                                      Markdown file for a Claude Project's knowledge base.
                                      <repo> defaults to the current directory. Prints the
                                      written path on success.
  chosko-llm export [<repo>] --archive  Same selection, written as a zip (top-level
                                      <repo>/ dir plus a root MANIFEST.md) for uploading
                                      to a Claude chat.

  chosko-llm task-impl <N> [<N>…]     Drive aider+Ollama through the 8-step /task-implement
  chosko-llm task-impl all            sequence for one or more backlog tasks in the current
                                      project. Requires /task-setup to have been run first.
                                      One commit per task.
                                      Run 'chosko-llm task-impl --help' for full options.

  chosko-llm uninstall                Remove the CLI proxy and, after confirmation, the installed
                                      features and the managed clone. Prompts before every
                                      destructive step; pass -y/--yes to answer all prompts yes.

  chosko-llm --version                Print the installed version (also: -v, 'version'). Matches the
                                      version banner shown by install.sh.

  chosko-llm help                     Show this help.

Feature names:
  Bare names (e.g. 'refactor-reviewer') match commands, skills, claude-md artifacts,
  statusline scripts, and hooks. If a name is ambiguous, disambiguate with 'command:<name>',
  'skill:<name>', 'claude-md:<name>', 'statusline:<name>', or 'hook:<name>'.
  claude-md artifacts inject managed sections into $CLAUDE_HOME/CLAUDE.md rather than copying
  a standalone file. Sections are delimited by HTML comments so user content is preserved.
  statusline scripts install to $CLAUDE_HOME/statusline/<name>.sh; 'add' then prints a prompt
  for a Claude Code session to wire the installed path into settings.json's "statusLine" key
  (this CLI does not edit settings.json itself).
  hooks install to <cwd>/.claude/hooks/<name>.sh and are local-only — a hook only fires where
  it is committed, and a cloud container clones the repo and nothing else. 'add' prints a
  prompt to wire it into the project's settings.json (again, never edited by this CLI). Commit
  both the script and settings.json, and restart the session: hook config is read at startup.

Environment:
  CHOSKO_LLM_HOME   Path to the managed clone. Default: ~/.chosko-llm
  CLAUDE_HOME       Path to Claude Code's user directory. Default: ~/.claude
  BIN_DIR           Where the CLI proxy is installed. Default: ~/bin
  NO_COLOR          Set to disable all colored output (table, metadata, log prefixes).
  CHOSKO_LLM_NO_AUTO_UPGRADE  Set to skip the daily auto-upgrade (CI / non-interactive use).
  CHOSKO_LLM_EXPORT_DIR  Where 'export' writes its output. Default: ~/claude-exports
