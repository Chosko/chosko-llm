# Task 63 — Exclude .claude/TASKS.md and .claude/tasks/ from export; add clear file separators to the Markdown output

Target: claude

## Goal
The task backlog (`.claude/TASKS.md` and the per-task bodies under
`.claude/tasks/`) is working-repo planning metadata — implementation
status, file lists, in-progress decisions — not part of a repo's Claude
config. `chosko-llm export` currently sweeps both in because
`select_export_files` in scripts/cmd-export.sh includes every `.md` file
under `.claude/`. Exclude them so exported hand-off artifacts don't leak
backlog noise. Separately, the Markdown bundle's per-file boundary is
currently a single easy-to-miss `FILE: <path>` text line; replace it with
a boxed, high-visibility banner so a reader (human or model) scanning the
concatenated file can't mistake where one source file ends and the next
begins.

## Acceptance criteria
- `select_export_files` no longer emits `.claude/TASKS.md`.
- `select_export_files` no longer emits any file under `.claude/tasks/`
  (pruned from the `find` traversal, matching how `.claude/projects`,
  `.claude/history`, and `.claude/todos` are already pruned — not just
  filtered post-hoc).
- All other current selection behavior (root files, other `.claude/*.md`
  /`.json`/`.toml` files, existing prune list, `settings.local.json`
  exclusion) is unchanged.
- The Markdown output's per-file separator becomes a fixed-width banner:
  a line of `=`, then `FILE: <path>`, then a matching line of `=`, e.g.:
  ```
  =========================================
  FILE: <path>
  =========================================
  ```
- The zip shape (`MANIFEST.md` + staged files) is unaffected — this
  changes the Markdown writer only.
- `.claude/context/cmd-export.md`'s "Selection" section documents the new
  exclusions, and its description of the Markdown layout reflects the new
  banner separator.

## Decisions
- Banner width fixed at 41 `=` characters (matching the sample given),
  rather than sized dynamically to each path's length — simpler to
  implement in `printf` and consistent across all files in a given
  export, at the cost of not framing very long paths exactly.

## Hints
- scripts/cmd-export.sh — `select_export_files` (prune group in the
  `find` call, plus a path exclusion for `.claude/TASKS.md`), and the
  Markdown-writer loop (currently `printf '\nFILE: %s\n\n' "$f"`).
- .claude/context/cmd-export.md — "Selection" bullets and any mention of
  the `FILE:` marker in the Markdown layout description.
- VERSION — patch bump (behavior fix to an existing command, not a new
  feature).
