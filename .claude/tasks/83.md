# Task 83 — Fix stale task-body schema in task-setup.md's external prompt templates

Target: claude

## Goal
commands/task-setup.md's "PER-TASK BODY FILE FORMAT (for reference)" section
(~lines 305-354) and the two verbatim EXTERNAL IMPLEMENT-PROMPT / EXTERNAL
TESTS-PROMPT templates it writes to every new project's
.claude/external/{implement,tests}-prompt.md (~lines 366-522) describe an
obsolete task-body schema (## Description, ### Files to modify, ### Required
reading, ### Relevant snippets, ### Conventions to follow, ### Out of scope,
### Root cause, ### Behavior change, ### Doc updates, ### Tests, ### Definition
of done). /task-add has not produced that schema for some time — its actual
schema (commands/task-add.md's PER-TASK BODY FILE FORMAT sections) is: a
Target line, then ## Goal, ## Acceptance criteria, ## Decisions (optional),
## Manual interventions (only when Target is claude+human/human), ## Hints,
plus ## Context bundle / ## Implementation steps for --enrich (Target: local)
bodies. Because task-setup.md writes both templates verbatim with no
interpolation, every project that runs /task-setup ships an aider prompt
telling the external LLM implementer to expect sections that never exist.
Fix the reference section and both templates to match the real schema.

## Acceptance criteria
- The "PER-TASK BODY FILE FORMAT (for reference)" section in
  commands/task-setup.md matches commands/task-add.md's actual schema:
  Target line, ## Goal, ## Acceptance criteria, ## Decisions (optional),
  ## Manual interventions (only for claude+human/human), ## Hints, plus
  ## Context bundle / ## Implementation steps for --enrich mode.
- Both templates' "## Inputs" bullet listing "Sections you should expect"
  is rewritten to name the real sections instead of the obsolete ones.
- Both templates' "## Procedure" steps are rewritten to work off the real
  sections: ground in Goal, honor Decisions and (if present) Manual
  interventions checkpoints, touch files under Hints plus genuine
  collateral, verify Acceptance criteria are observable. Drop references
  to "Required reading" (replace with "read CLAUDE.md and the
  context/domain layer directly") and "Conventions to follow" (same).
- The tests-prompt.md template's test-writing pass is re-anchored to
  Acceptance criteria plus test-file paths named in Hints, since there is
  no dedicated "Tests" section in the real schema.
- No content in commands/task-setup.md changes outside this reference
  section and the two templates.

## Decisions
- Rewrite the guidance to fit the real schema rather than just deleting
  unmatched bullets, so the templates stay coherent for an aider agent
  that only has the task body and these prompts to work from.
