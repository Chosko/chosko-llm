# Task 101 — Document the context skill family and refresh its context layer

Target: claude

## Goal
Tasks 97–100 turn two commands into three skills and add a whole layout
mode. The user-facing documentation, the shipped CLI help, this repo's own
context layer, and the commands that reference `/context-build` all still
describe the old shape. Bring them current in one sweep, after the
behaviour has landed.

## Acceptance criteria
- `README.md` lists `/context-build`, `/context-update`, and
  `/context-convert` as skills, and explains the flat-default /
  nested-on-demand model in the depth the README uses for other features.
- `docs/cli-help.txt` reflects the kind change wherever the context
  features are named.
- `docs/authoring-guide.md` is consistent with the family's final shape —
  including the `replaces:` key from task 95 if its guidance needs
  sharpening once a real migration has shipped.
- `.claude/context/features.md` describes the three skills, their supporting
  files, and which is read on demand.
- `.claude/context/INDEX.md` is accurate and carries `Layout: flat` — this
  repo's own layer stays flat, and is the reference example of a
  marker-bearing flat index.
- `commands/project-setup.md` invokes and describes the context step
  correctly now that `/context-build` is a skill, including whether the
  wizard offers the nested option (state the answer explicitly rather than
  leaving it implied).
- `.claude/domain/context-workflow.md` is a complete and current account of
  the family: three skills, both layouts, the marker, the leaf-date rule,
  the two-level cap.
- Every cross-reference between these files resolves.
- Root `VERSION` bumped patch (docs-only), unless the project-setup edit
  changes behaviour, in which case minor.

## Decisions
- **Docs land last, in one task.** Splitting them across 97–100 would mean
  four passes over the same files describing intermediate states that never
  ship to a user.
- **This repo stays flat.** It has thirteen context files and no unit
  seams worth a router; keeping it flat also keeps a live flat example in
  the tree.
