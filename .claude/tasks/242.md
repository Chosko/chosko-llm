# Task 242 — Rewrite the runbook-suite and remaining descriptions; hide the wizards; refresh the local install

Target: claude

## Goal
Apply task 240's description contract to the other 18 features — the runbook
suite, `session-*`, `context-*`, `refactor-*`, the two setup wizards,
`unity-mcp-skill`, `claude-council` and `runbook-suggest` — set
`disable-model-invocation: true` on the one-shot wizards and housekeeping
commands that are never useful to auto-suggest, give `unity-mcp-skill` a
`paths:` filter so it loads only in Unity projects, refresh this repo's own
local install under `.claude/`, and report the before/after size of the
rendered skill list so the saving is on record.

## Acceptance criteria
- Every `description:` in the Files list is within budget: ≤ 60 words / 400
  chars for manual features; `claude-council` and `runbook-suggest` ≤ 150
  words / 1,000 chars, trigger phrases first, "Not for" last. None contains
  ` --- `. `runbook-run`'s description is ≤ 400 chars and every one of its
  flags (`--from`, `--to`, `--only`, `--steps`, `--inline`, `--model`,
  `--relay-spawns`, `--no-commit`, `--no-push`) is in its `#` header.
- `disable-model-invocation: true` is set on `commands/project-setup.md`,
  `commands/unity-mcp-setup.md`, `commands/runbook-prune.md`,
  `commands/runbook-clean.md`, `commands/refactor-codebase.md`,
  `commands/refactor-tests.md`, and on `commands/task-setup.md` if task 241
  did not set it.
- `skills/unity-mcp-skill/SKILL.md` carries `paths:` covering `Assets/**`,
  `ProjectSettings/**` and `Packages/**`.
- For every feature, each flag or argument named in the old description is
  present in the body's `#` header after the change.
- Measured over `commands/*.md` + `skills/*/SKILL.md`, the sum of
  `- name: description\n` lengths is ≤ 10,000 chars (from 45,111 at v1.57.4),
  no single description exceeds 1,000 chars, and the before/after figures
  are reported in the closing message and in the CHANGELOG bullet.
- This repo's own `.claude/commands/` and `.claude/skills/` copies of the
  features it installs locally are refreshed from the working tree (the way
  commit c9649ba "Refresh this repo's local install of its own features"
  did), so sessions on this repo see the new descriptions.
- Each touched feature bumps its own `version:` (patch); root `VERSION` patch
  bump with a `CHANGELOG.md` entry; `./scripts/check-changelog.sh`,
  `./scripts/check-home-paths.sh` and `./scripts/check-routing.sh` silent;
  `./bin/chosko-llm ls --available` lists every feature with its new version.

## Decisions
- **The wizard set loses its place on the map by design.**
  `disable-model-invocation` removes the description from context entirely;
  nothing in this set is ever useful for the model to suggest unprompted,
  and each is reachable by typing its name.
- **Measurement without a tokenizer.** Chars of the rendered `- name:
  description` lines, summed with awk over the frontmatter; the
  10,000-char target is ~2,500 tokens at 4 chars/token.
