# Task 256 — `/doc-consolidate`: one gate per run, judgement calls only, auto-approved when there are none

Target: claude

## Goal
`/doc-consolidate` gates once per section, rendering that section's full
ledger and waiting for `Rewrite § <section>?`. On a large body that is
eighteen ledgers and a wall the user cannot read; the entries that need a
person are a handful. Make the run classify everything first — every
section of every file — write the full ledgers to the session scratchpad,
and stop once, at a single gate listing only the judgement calls across all
files and sections as one numbered list. A run with no judgement calls
proceeds without asking.

## Acceptance criteria
- `skills/doc-consolidate/SKILL.md` step 3 classifies every section of
  every file in the run before anything is asked, writes each file's full
  per-section ledger (the existing ledger shape, unchanged) to one file in
  the session's scratchpad directory, never inside the repository, and
  prints its path once.
- The section defines a **judgement call** — a superseded pair whose two
  versions disagree on the rule; a drop or merge that changes what the
  document says rather than where it says it; any entry the discipline's
  rules cannot settle mechanically — and states that duplicates kept
  elsewhere, rules restated beside their citation, historical tails, rule-6
  DO NOT bullets and meaning-preserving merges are never judgement calls.
- Step 4 is one gate per run: a numbered list of every judgement call across
  all files and sections, each one short block naming the file and section,
  the entry, the options and a recommendation, followed by one count line per
  file (`<path>: <n> statements, <k> kept, <d> dropped, <m> merged`). The
  user answers once — `all` approves; numbers overrule, keeping those entries
  as they were; `ledger` prints the ledgers in chat and re-asks. Silence, an
  unclear reply or EOF writes nothing.
- A run with zero judgement calls prints the count lines and the ledger path
  and continues to step 5 without asking. `--commit` is unchanged.
- Step 5 (rewrite and verifier) and the report are unchanged, per file.
- `docs/reference.md` § `/doc-consolidate` and `.claude/context/features.md`
  describe the single gate, the judgement-call rule and the auto-approve.
- `skills/doc-consolidate` `version:` minor bump; root `VERSION` bump;
  `CHANGELOG.md` section; `./scripts/check-changelog.sh` and
  `./scripts/check-home-paths.sh` silent.

## Decisions
- Zero judgement calls means no gate: the discipline's rules settled
  everything, and the verifier is the check that nothing was lost.
- Numbered items are the handle, matching `/follow-ups` and the closing-report
  convention task 255 set.
- Under `/runbook-run` nothing changes there: the step's agent carries this
  single gate in its `QUESTIONS FOR USER`, or reaches `DONE` without one.
