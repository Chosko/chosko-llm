# Task 297 — Author parallel runbooks in /runbook-create

Target: claude

## Goal
Let `/runbook-create` write a runbook built for its graph, per feature
`parallel-runbooks`. A runbook meant to run in parallel is one whose every
ordering constraint is an edge, so the command writes the `Parallelism:`
header line on request, refuses to put it beside a `Sequencing:` line, and
asks the sequencing question exhaustively rather than as a check on the
list, so that a step without an edge is independent by the author's
declaration and not by omission.

## Acceptance criteria
- When the user asks for a parallel runbook — by saying so, or by naming a
  parallelism — PHASE 4 writes `Parallelism: <N|max>` in the header where
  `Execution policy:` goes, with the same ownership rules; it is never
  written by default, and the header-field table gains its row.
- A header never carries both `Parallelism:` and `Sequencing:`: on a
  parallel runbook the *why* that `Sequencing:` would hold is written as
  edges instead, and the command says so in one line if the user offers a
  sequencing note; on an append to a runbook carrying `Parallelism:` no
  `Sequencing:` line is written, as none is on any append.
- On a parallel runbook PHASE 2's question "which steps must precede which,
  and why" is asked exhaustively: for every pair the author might order
  either an edge is written or the two are declared independent; the gate's
  step table states that every step without an edge is independent of
  every step not reachable from it, so the user approves the graph and not
  only the list.
- `--append` onto a runbook carrying `Parallelism:` authors the new steps'
  `Depends on:` lines under the same duty, against the existing steps
  included; an existing step's `Depends on:` is still never rewritten.
- A runbook with no `Parallelism:` line is authored exactly as today.
- `pipeline-engine`'s `routing.md` row for `/runbook-create` lists the
  header line it may write; `./scripts/check-routing.sh` and
  `./scripts/check-home-paths.sh` pass.
- `runbook-create`'s `version:` is bumped (minor); root `VERSION` is bumped
  (minor) with a matching `CHANGELOG.md` section; `./scripts/check-changelog.sh`
  passes.
