## Goal
`docs/` is authoring-time-only and never installed (CLAUDE.md § Authoritative references), yet ten shipped bodies send the executing agent to `docs/authoring-guide.md` — inline "(docs/authoring-guide.md)" parentheticals and "per docs/authoring-guide.md's commit-and-push protocol" — so on an installed machine the citation resolves to nothing. Make every one of them state its commit-and-push steps itself.

## Acceptance criteria
- No shipped body under `commands/`, `skills/`, `claude-md/`, `statusline/`, `hooks/` cites chosko-llm's `docs/authoring-guide.md` as something to read or follow at run time. The occurrences to remove: `commands/refactor-codebase.md` (~77, ~303), `commands/refactor-tests.md` (~50, ~183), `commands/unity-mcp-setup.md` (~53, ~69, ~331), `commands/task-setup.md` (~51, ~70, ~159), `commands/domain-setup.md` (~54, ~75, ~259), `commands/project-setup.md` (~128, ~509), `skills/product-design/SKILL.md` (~89, ~430), `skills/product-roadmap/SKILL.md` (~74, ~411), `skills/architect/SKILL.md` (~98, ~436), `skills/task-engine/references/commit.md` (~32 bare inline path; ~78 "per docs/authoring-guide.md's commit-and-push protocol").
- Each body states the steps it performs itself (pull at start → commit → pre-push re-sync → push, with its own conflict/failure handling as it already words it), with no change to what any feature does.
- `skills/task-engine/references/commit.md`'s header note — which names the guide as where the protocol was authored, explicitly "never an instruction to open that path" — stays, reworded only if it still claims the consumers defer "by name" when they no longer do.
- Mentions of a project's own `docs/` folder are untouched: `skills/task-implement/SKILL.md` (doc-only test), `skills/context-build/SKILL.md`, `skills/context-update/SKILL.md`, `commands/runbook-create.md` ("nothing under `docs/`"), `commands/task-add.md` (documentation-hint list).
- Patch bump of every touched feature's `version:` frontmatter and of root `VERSION`, with a matching `CHANGELOG.md` section; `./scripts/check-changelog.sh` and `./scripts/check-home-paths.sh` pass.

## Decisions
- **Self-contained wording, not a cited file.** Only the task-* suite requires `task-engine`, so other bodies cannot rely on `references/commit.md` being installed; each names its own steps.
- **No guard script.** A grep cannot tell the forbidden runtime citation from legitimate mentions of a project's `docs/` (`/task-add`'s documentation-hint list names `docs/authoring-guide.md` legitimately).
- **Patch bump** — a fix to existing bodies, no new surface.
