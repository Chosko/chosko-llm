# Task 295 — Add slug resolution to `/session-resume`

Target: claude

## Goal
Part of feature `session-readers`. `/session-resume` resolves a handoff by
path, date or nothing; a session's slug — the one human-readable part of its
filename — cannot be typed to reach it. Add the slug form and make
`/session-resume`'s body the single home of the path/date/slug resolution
rule, written so `/session-describe` (task 297) can apply it by name.

## Acceptance criteria
- `commands/session-resume.md` ARGUMENT PARSING states four forms, tried in
  order: a path (contains `/` or `\`, or ends `.md`) read as given with no
  candidacy check; a date `YYYY-MM-DD` → newest candidate from that day; a
  slug (anything else) → the newest candidate whose filename's slug part
  (after `YYYY-MM-DD-HHMM-`, before `.md`) equals it exactly; nothing → the
  newest candidate.
- Several exact slug matches resolve to the newest by the existing
  full-filename tie-break; the picked file is named on the first output line
  as today.
- A slug with no exact match names the nearest existing slugs and stops; no
  substring or fuzzy fallback, no fall-through to the newest candidate. The
  FAILURE CONTRACT table gains this row, and the section heading/intro state
  it as the one exception to degrade-never-refuse, with its reason (guessing
  the newest file for a typed name loads the wrong session).
- A bare number is still unrecognized: said in one line, run continues with
  the newest candidate.
- The rule is written as one self-contained section another command can
  cite by name ("the resolution rule in `/session-resume`"); FINDING THE FILE
  states that only top-level files carrying a `Work:` line are candidates —
  subfolders under `.claude/sessions/` and their contents are skipped
  silently.
- `# Usage:` / `# Examples:` header, `description:` and the DO NOT list
  reflect the slug form; read-only and shell rules unchanged (slug matching
  uses the file listing, never `ls`/`grep`).
- `version:` bumped 0.1.1 → 0.2.0; root `VERSION` minor-bumped with a
  `CHANGELOG.md` section; `check-changelog.sh` and `check-home-paths.sh` pass.

## Decisions
- Bare number keeps today's degrade-to-newest behaviour rather than being
  treated as a slug — the feature document says a bare number is
  unrecognized, and no slug `/session-save` generates is purely numeric.
- "Nearest slugs" is left to the implementer's judgement (shared prefix /
  shared words), capped at a handful; no algorithm is specified.
