# Task 266 — Parked items across the read-only and lint commands

Target: claude

## Goal
Part of feature `unattended-parking`. Once a task can be `[PARKED]` and a
step `[P]`, the commands that read the backlog and the indexes must
recognise them, each in one line: `/task-list` marks a parked task,
`/task-clean` never prunes one by default, `/pipeline-check` reports the two
structural inconsistencies parking can leave, `/task-add feature=<slug>`
reconciliation knows what to do with a parked task, and the routing table
lists the new flags so `check-routing.sh` stays green.

## Acceptance criteria
- `commands/task-list.md`: a `[PARKED]` task carries a trailing `⚠ parked`
  marker in the same position and register as `⚠ stale`, and the status
  column width note reflects the new tag set; the status filter accepts
  `parked`.
- `skills/task-clean/SKILL.md`: `[PARKED]` joins `[STALE]` in the
  never-in-the-default-set rule and the DO NOT list; when named explicitly
  the plan carries `status.md`'s warning for it (the parking branch is
  named as what a prune would orphan).
- `/pipeline-check` (`commands/pipeline-check.md` and the lint catalogue in
  `skills/pipeline-engine/references/`) gains two findings, each with its
  severity and the one command that fixes it: a `[PARKED]` task whose body
  has no `## Parking handoff` section (fix: `/task-implement <N>` under
  attended, which unparks or reports), and a `[P]` step in a body whose index
  block has no `Parked:` line, or the reverse (fix: `/runbook-run <id>`,
  which rewrites the index from the body). No probe of branch existence.
- `skills/task-engine/references/stale.md` § *Clearing it* gains the row for
  a `[PARKED]` task: classified as `[MISSING]` is; on update-in-place the
  handoff and the branch are left as they are; on skip-and-replace the
  parking branch is deleted local and remote and the reason names it.
  `commands/task-add.md`'s RECONCILIATION example shows one such row.
- `skills/pipeline-engine/references/routing.md`: the `/task-implement`
  row's arguments gain `[--unattended [--skip-parked]]` and its writes
  `[PARKED]`; the `/runbook-run` row's arguments gain
  `[--attended | --unattended [--skip-parked]]` and its writes `[P]`,
  `Parked:`, the two `Context:` bullet forms; `./scripts/check-routing.sh`
  passes.
- Frontmatter `version:` bumped on `task-list`, `task-clean`,
  `pipeline-check`, `pipeline-engine`, `task-engine`, `task-add` (patch);
  root `VERSION` bumped (patch) with a matching `CHANGELOG.md` section;
  `./scripts/check-changelog.sh`, `./scripts/check-home-paths.sh` and
  `./scripts/check-routing.sh` pass.

## Decisions
- No branch-existence finding: git state across machines makes it noise,
  and an absent branch is reported by the unpark that needs it.
- `/architect` is untouched: it leaves `[PARKED]` alone by having no rule
  for it, which is the rule.
