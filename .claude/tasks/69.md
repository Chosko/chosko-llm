Target: claude

## Goal
Apply the commit-and-push protocol from task 68 to the four task-backlog
commands, each of which currently ends its PHASE 5/final step with a plain
`git commit`. task-add and task-clean are auto-committing (add
`--no-push`, implied by existing `--no-commit`); task-setup and
task-enrich are authoring commands (push only fires when `--commit` was
passed; add `--no-push` to allow committing without pushing).

  protocol rather than re-describing it.
- README.md's command reference for these four commands mentions the push
  behavior and `--no-push` where it currently documents `--commit`/
  `--no-commit`.
- Root VERSION bumped (minor).
