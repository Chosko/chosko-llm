# Task 257 — `/follow-ups` renders its list under a `Follow-ups` heading

Target: claude

## Goal
When `/follow-ups` has items, render the numbered list under a `Follow-ups`
heading, so a reader scanning a long turn sees where the list starts. The
exact `No follow-ups left` line stays bare.

## Decisions
- Heading only above the list: the no-items answer is a fixed exact string
  other bodies match on, and a heading over one line adds nothing.
