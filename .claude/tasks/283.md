# Task 283 — Adopt the interaction policy in the runbook suite

Target: claude

## Goal
Make `/runbook-run`, `/runbook-create`, `/runbook-clean` and
`/runbook-prune` adopt feature `interaction-policy`, including the three
contract changes the feature names for `/runbook-run`: the policy handed to a
step under both values, the never-skip-a-gate rule giving way to class 1
under `unattended`, and plain-summary relays in place of verbatim drafts.

## Acceptance criteria
- Each listed feature declares `requires: skill:interaction-engine`, cites it
  relatively, accepts both flags, and tags every gate.
- `/runbook-run`: `--attended` / `--unattended` and the `Execution policy:`
  header resolve via `policy.md` (the header ranks second); its own
  resolution passage is replaced by the citation; the step preamble states
  the resolved policy under both values ("This run is attended" /
  "This run is unattended"); the never-skip-a-gate rule in `SKILL.md`,
  `subagent-contract.md` and `inline-contract.md` holds under `attended` and
  for classes 2–3 under `unattended`, and a class 1 gate passing on its own
  is stated as not a skipped gate; the relay block, subagent contract and
  inline contract drop "full draft verbatim and unabridged" for the plain
  summary + `show`; parked-question lines in `references/parking.md`
  rewritten to the question rules; the closing report follows the output
  rules.
- `/runbook-create`'s gate and the step-amend gate tagged class 1;
  `/runbook-clean` and `/runbook-prune` tagged class 3.
- No restated engine rule remains. Feature `version:`s and root `VERSION`
  bumped with a `CHANGELOG.md` section; `check-changelog.sh`,
  `check-home-paths.sh` pass.
