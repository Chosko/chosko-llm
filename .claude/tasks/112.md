# Task 112 — Update documentation for feature production-plan

Target: claude

## Goal
Feature `production-plan` ships `/production-plan` and a third index,
`.claude/PLAN.md`, beside `TASKS.md` and `FEATURES.md`. The documentation
describing the product pipeline predates all of it: the pipeline table stops
at stage 4, the artifacts tree has no `PLAN.md`, the who-writes-what table
has no row for it, and the README, CLI help and context layer list no such
skill. Bring every layer up to date with the shipped behavior.

## Acceptance criteria
- `README.md` lists `/production-plan` among the shipped skills with a
  one-line description matching its frontmatter.
- `docs/cli-help.txt` lists the skill wherever the other pipeline skills
  appear.
- `.claude/context/features.md` gains a row/section for
  `skills/production-plan/`, covering `SKILL.md` and `reconciling.md`, in the
  same shape as the other skill entries.
- `.claude/domain/product-workflow.md` covers: `PLAN.md` in the artifacts
  tree, the milestone status vocabulary as the third vocabulary in the
  pipeline, a who-writes-what row naming `/production-plan` sole writer of
  `PLAN.md`, and the fact that the skill reads `FEATURES.md`, the feature
  documents, the roadmap and `TASKS.md` read-only.
- `.claude/domain/features/production-plan.md` is reviewed against what
  actually shipped and its open questions updated where implementation
  settled them. Anything still genuinely open stays open.
- Root `VERSION` bumped patch (documentation-only change).
