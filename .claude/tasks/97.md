# Task 97 — Convert /context-build and /context-update to skills and emit the Layout marker

Target: claude

## Goal
Nested support must not cost tokens on flat runs, which is what skills with
read-on-demand supporting files buy: `SKILL.md` carries the flat path, a
sibling `nested.md` (added in tasks 98/99) is opened only when the marker
says nested. Move both commands to skills with their flat behaviour
preserved exactly, and teach them the `Layout:` marker from task 96. This
task adds no nested behaviour of its own.

## Acceptance criteria
- `commands/context-build.md` becomes `skills/context-build/SKILL.md` and
  `commands/context-update.md` becomes `skills/context-update/SKILL.md`,
  with `type: skill` frontmatter, unchanged `name` and `description`, and
  a minor `version` bump on each.
- Body content is moved, not rewritten. Every phase, mode, flag, gate, and
  report of both commands behaves identically for a flat layer — same
  reads, same single `Last updated`, same single-index bump, same staging,
  same commit/push behaviour. A flat run is indistinguishable from today.
- Each new skill's frontmatter carries `replaces: command:<name>` (task 95)
  so existing installs migrate on `chosko-llm update --all`.
- The old `commands/*.md` files are deleted; the migration key, not a stub,
  handles the stale installs.
- `/context-build` writes `Layout: flat` into the `INDEX.md` header it
  authors in Phase 2, directly under the title.
- `/context-update` backfills the marker: on any layer whose `INDEX.md` has
  no `Layout:` line, it adds `Layout: flat` as part of the step 2.4 index
  update. This is the migration path for every context layer built before
  the marker existed, so it must fire on every mode, including Mode A runs
  that update no other file — in that case `INDEX.md` alone is written,
  staged and committed.
- Both skills read the marker in PREPARATION / Phase 1 and state the
  detected layout in their scope report. A `Layout: nested` marker at this
  point is not yet supported: report it and stop cleanly, telling the user
  the nested path arrives with tasks 98/99. No half-handled nested run.
- `.claude/domain/context-workflow.md` updated: both are skills now, and
  the marker-backfill behaviour is recorded.
- Root `VERSION` bumped minor.

## Decisions
- **Delete the commands rather than leave deprecation stubs.** Task 95's
  `replaces:` key removes the stale installed copy, so a stub would be dead
  weight in the repo and a second definition of the same slash command.
- **Fail loudly on a nested marker in this task.** A skill that silently
  treats a nested layer as flat would stamp dates and stage files wrongly;
  stopping is the only safe intermediate state between 97 and 98/99.
- **Backfill on a Mode A no-op run.** Committing an INDEX.md whose only
  change is the marker looks like churn, but it is what makes every
  existing project self-migrating without a separate command.
