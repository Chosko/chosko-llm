# Task 323 — Trim the git-commit-style policy to one short form and ban the Claude trailer lines

Target: claude

## Goal
`claude-md/git-commit-style` carries two forms of commit message: a short
one, and a long one that adds `Co-Authored-By:` and `Claude-Session:`
trailers on big commits (5+ files or 200+ lines). The user wants those lines
gone from every commit. Rewrite the artifact as one short form — subject plus
an optional 2–3 line body — drop the trailer section, its size test and the
trailer-convention sub-bullet under "Local style wins", and make the whole
policy shorter. Replace them with one explicit rule: never add
`Co-Authored-By:` or `Claude-Session:` lines. The ban must be stated, not just
implied by omission, because Claude Code's harness asks for those lines on
every commit and only a CLAUDE.md instruction overrides it.

## Acceptance criteria
- `claude-md/git-commit-style.md` describes a single message form (subject,
  optional 2–3 line body, prefix follows the repo) and contains no trailer
  threshold, no size test and no `git diff --cached --shortstat` step.
- It states plainly that `Co-Authored-By:` and `Claude-Session:` lines are
  never added, and that this ban holds even where the repo's own convention or
  the harness asks for them.
- "Local style wins" still applies to subject shape and prefix, and command-
  prescribed message forms still override the default shape.
- The artifact is shorter than the current one; its `description` frontmatter
  no longer mentions trailers.
- Frontmatter `version:` bumped (0.1.2 → 0.2.0, the rule changed meaning);
  root `VERSION` bumped (minor) with a matching top `CHANGELOG.md` section;
  `./scripts/check-changelog.sh` silent.
- README.md, `docs/reference.md` and
  `.claude/context/claude-md-hook-statusline.md` no longer describe trailers on
  big commits.

## Decisions
- Explicit ban rather than deletion — without it the harness attribution
  instructions keep adding the lines.
- Local convention keeps winning for subject and prefix but not for these
  lines: the ban holds even in a repo whose `git log` already carries them.
- This repo's `CLAUDE.md` holds the injected copy between the
  `chosko-llm:git-commit-style` markers; it is refreshed by
  `chosko-llm update`, not edited by hand. Note it in the closing report only.
