# Task 279 — Accept a bare `--commit` as a silent no-op on every commit-by-default feature

Target: claude

## Goal
Seven commit-by-default features (`/product-design`, `/product-roadmap`, `/architect`, `/production-plan`, `/pipeline-revise`, `/runbook-create`, `/session-save`) accept a bare `--commit` as a silent no-op. The rest handle it unevenly: `task-engine`'s `references/commit.md` (used by `/task-add`, `/task-clean`, `/task-implement`), `/task-iterate` and `/context-update` mention `--commit` only to refuse it beside `--no-commit`, so `/task-add` leaves a bare `--commit` inside the task description; `/runbook-run`, `/runbook-clean` and `/runbook-prune` never mention it. Make every commit-by-default feature strip a bare `--commit` and ignore it, still refusing it beside `--no-commit`, and state that once as a rule in the authoring guide.

## Acceptance criteria
- `skills/task-engine/references/commit.md` § The flags states that a bare `--commit` is accepted and stripped as a silent no-op, and that `--commit` beside `--no-commit` is refused with the existing message; `/task-add`, `/task-clean` and `/task-implement` inherit it (their bodies strip it from what they parse — a bare `--commit` never reaches `/task-add`'s description).
- `/task-iterate`, `/context-update`, `/runbook-run`, `/runbook-clean` and `/runbook-prune` each accept a bare `--commit` as a silent no-op and refuse it beside `--no-commit`, in their own argument parsing.
- `docs/authoring-guide.md` § Commit-and-push convention states one rule — every feature that commits by default accepts a bare `--commit` as a silent no-op — in place of its list of seven; `docs/reference.md` matches wherever it describes `--commit` on a commit-by-default feature.
- No other behaviour changes.
- Patch bump of every touched feature's `version:` and of root `VERSION`, with a matching `CHANGELOG.md` section; `./scripts/check-changelog.sh` and `./scripts/check-home-paths.sh` pass.

## Decisions
- **One rule in the guide, not a list** — so a new commit-by-default feature cannot fall out of it.
- **Waits on 278** — both edit `references/commit.md` and the guide's commit section.
- **Patch bump** — a consistency fix to existing flags.
