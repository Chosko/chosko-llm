# Task 205 — Update documentation for feature `authoring-commit-default`

Target: claude

## Goal
Tasks 202–204 change the commit default of `/architect`,
`/product-design`, `/product-roadmap` and `/production-plan`, and correct
the two forwarding tables that record those defaults. The documentation
layers still describe the old behaviour: the README's planning section, the
reference, the authoring guide's two-group split, the product workflow's
commit section, the context layer's feature rows, and three
`/architect`-owned feature documents. Bring them up to date with what
shipped.

This task ships no behaviour, so it bumps no `VERSION` and gets no
`CHANGELOG.md` entry — see `CLAUDE.md` § Versioning, under which project
documentation is exempt.

## Acceptance criteria
- `docs/authoring-guide.md` § *Commit-and-push convention*: the four skills
  move from the authoring (uncommitted-by-default) group to the
  auto-committing group. The authoring group keeps `/context-build`,
  `/context-convert`, `/refactor-codebase`, `/refactor-tests`,
  `/task-setup`, `/domain-setup`, `/unity-mcp-setup`, `/project-setup` and
  `/runbook-create`, and the sentence about which kinds ship as skills is
  corrected if it names a moved skill as an example of the wrong group.
- `.claude/domain/product-workflow.md` § *Commit and push*: the "all five
  authoring commands/skills — uncommitted by default" sentence is split —
  `/domain-setup` keeps the old default; the four do not. The forwarding
  paragraph matches the tables as task 204 leaves them.
- `README.md` § 4: the line reading "`/production-plan` is uncommitted by
  default; `/task-add` commits and pushes" states the new grouping.
- `docs/reference.md`: the `/pipeline-revise` paragraph naming which owner
  steps get `--commit` and which get `--no-commit` matches task 204's
  tables.
- `.claude/context/features.md`: the rows for `skills/architect/`,
  `skills/product-design/`, `skills/product-roadmap/` and
  `skills/production-plan/` state the new default; the rows for
  `commands/pipeline-patch.md` and `skills/pipeline-revise/` state the new
  forwarding. `.claude/context/INDEX.md`'s `Last updated` anchor is
  refreshed.
- The four granted feature-document edits below are made, each confined to
  the single point named.
- No `VERSION` bump and no `CHANGELOG.md` entry.
- `./scripts/check-changelog.sh` is silent (it should be unaffected).
