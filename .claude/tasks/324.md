# Task 324 — `/context-update`: split oversized context files automatically and suggest `/context-convert` for large flat layers

Target: claude

## Goal
On many projects context files grow without bound under `/context-update`,
because Phase 2 step 2.1f only flags a file past the 150-line cap and never
splits it, and 2.4 forbids new context files in an update run. Make the cap
self-enforcing: Phase 1's report names each in-scope file the update will push
past 150 lines together with the planned split, so the split is approved at
that existing gate; Phase 2 then performs it — two focused files, each keeping
the six-section schema, INDEX entries added/updated, sibling CROSS-REFERENCES
repaired — and Phase 3 stages both files. Separately, when a flat layer holds
more than 40 context files, the P.4 scope report (the first gate) suggests
running `/context-convert` to nest it — a suggestion only, never acted on,
never a question gating the run. Mirror both in `nested.md` (splits happen
inside the owning leaf; the convert suggestion does not apply).

## Acceptance criteria
- `skills/context-update/SKILL.md` 2.1f splits instead of flagging; Phase 1's
  report lists predicted splits with the proposed division; 2.4 allows the new
  files a split creates (and only those); Phase 2's report lists splits made;
  Phase 3's staging covers both halves of a split.
- Only files the run updates are split; `full` mode reaches every file.
- P.4 on a flat layer with more than 40 context files carries a one-line
  `/context-convert` suggestion; it does not stop or ask anything extra, and
  is not printed on a nested layer.
- Under `-y` / `unattended` the split proceeds with no added gate.
- `skills/context-update/nested.md` states the split rule for leaves (new file
  lands in the same unit, leaf INDEX updated) and that the convert suggestion
  is flat-only.
- Skill `version:` bumped (minor), root `VERSION` bumped (minor) with a
  matching top `CHANGELOG.md` section; `./scripts/check-changelog.sh` and
  `./scripts/check-home-paths.sh` silent.
- `.claude/domain/context-workflow.md` no longer says files are "flagged for
  splitting, not split automatically", and describes the suggestion;
  `.claude/context/context-skills.md` and `docs/reference.md` updated where
  they describe the flag.

## Decisions
- Split scope is in-scope files only; `full` catches already-bloated layers.
- The convert suggestion is flat-only — on a nested layer `/context-convert`
  could only flatten it.
- Threshold: more than 40 context files (user's choice).
- The split is surfaced at the existing Phase 1 gate rather than a new gate.
