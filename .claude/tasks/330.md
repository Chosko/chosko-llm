# Task 330 — Add the Files: overlap rule and the Parallel-safe files marker

Target: claude

## Goal
Under `/task-implement --parallel` (feature `parallel-task-runs`), keep two
tasks whose `Files:` lines intersect from being in flight at the same time:
when one is in flight the other is held back until it lands, whatever N
says, and re-examined at the next scheduling point. A conflict avoided is
cheaper than one the integrating agent resolves, and `Files:` is on the
summary block, so the rule costs no read. Let a project exempt files whose
conflicts that agent resolves mechanically — a version counter, a
newest-first changelog — with one `CLAUDE.md` marker, read at pre-flight
beside the testing-policy marker. Declare it for this repository, where
every shipped task lists `VERSION` and `CHANGELOG.md`.

## Acceptance criteria
- `delegated-runs.md`'s scheduler, at each scheduling point, holds back a
  task whose `Files:` paths intersect those of any task in flight, with one
  line naming the task it waits on; the task is re-examined at the next
  scheduling point. An empty or missing `Files:` holds nothing back and is
  never held back. The rule is stated as a safety net under
  `Preconditions:`, not a second dependency graph.
- `/task-implement` reads, once at pre-flight and only when PARALLEL is set,
  a `CLAUDE.md` marker of the form
  `Parallel-safe files for /task-implement: <path>, <path>` — the same
  marker-reading shape as `Testing policy for /task-implement:` — and
  removes every listed path from every `Files:` line before the
  intersection is taken. No marker means no exemption. The marker is
  documented in SKILL.md's header comment beside the testing-policy one.
- This repository's `CLAUDE.md` carries
  `Parallel-safe files for /task-implement: VERSION, CHANGELOG.md`, placed
  beside its `Testing policy for /task-implement:` line, with no further
  prose: the marker is the rule.
- `task-implement`'s `version:` is bumped; root `VERSION` is bumped (patch)
  with a matching `CHANGELOG.md` section; `./scripts/check-changelog.sh`
  and `./scripts/check-routing.sh` pass.

## Decisions
- The exemption is a repo-level `CLAUDE.md` line, not a flag: which files
  are safe to collide on is a property of the project's conventions, the
  same reason the testing policy lives there.
- Settled here, without conflict with the feature document: the marker's
  wording is `Parallel-safe files for /task-implement:`, the document's own
  proposal, so the two `/task-implement` markers read alike.
