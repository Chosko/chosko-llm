# Task 214 — Update documentation for feature `runbook-id-filenames`

Target: claude

## Goal
Feature `runbook-id-filenames` (.claude/domain/features/runbook-id-filenames.md) changes
the runbook body path to `<id>-<name>.md`, makes `File:` the only source of a body path,
accepts `<id|name|id-name>` wherever a runbook argument is taken, and migrates legacy
bodies lazily. The documentation describing the runbook store still says the body stays
`<name>.md` and that an argument is "all digits → id, else name"; bring it in line with
what tasks 211–213 shipped. Documentation only — no `VERSION` or `CHANGELOG.md` entry.

## Acceptance criteria
- `docs/reference.md` — the `runbook=` anchor (~line 540), `/runbook-describe`
  (~line 1025), the id paragraph (~line 1034) and the store paragraph (~line 1039)
  state the new body path, `File:` authority, the three argument forms and lazy
  migration.
- `docs/authoring-guide.md` (~line 553) shows the new body path.
- `.claude/domain/product-workflow.md`'s anchor line (~line 331) reads
  `runbook=<id|name|id-name> step=<n>`.
- `.claude/context/features.md` — the runbook asset-kind summary (~lines 1193,
  1216–1217) no longer says the body stays `<name>.md` and names `body-migration.md`;
  the runbook-run, runbook-create, runbook-clean, runbook-describe, pipeline-patch,
  pipeline-revise and pipeline-engine entries reflect the shipped change.
- `.claude/context/INDEX.md` `Last updated` advanced.
- `.claude/domain/features/runbook-suite.md` is reconciled with what shipped on exactly
  these 4 points — editing it is authorised for this task, see Decisions:
  1. § The store (~line 160): the body path becomes `.claude/runbooks/<id>-<name>.md`,
     with `File:` as the authority for a body's path.
  2. The id-as-alias paragraph (~lines 172–182) no longer says "the body file is still
     `<name>.md`"; it states the three-form argument rule in place of "all digits → id,
     else name", keeping the id an alias, not the identity.
  3. The name-collision rule (~line 182) gains the restriction that a new name whose
     first kebab segment is all digits is refused with a suggested alternative.
  4. The index-block example (~line 298) shows `File: .claude/runbooks/<id>-<name>.md`.
  Nothing else in the document changes.
